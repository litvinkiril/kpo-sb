# Московский зоопарк — консольное приложение

Консольное приложение позволяет Московскому зоопарку вести учет животных и материальных
ценностей. Перед постановкой на баланс каждое животное проходит осмотр ветеринарной клиники.
Система формирует отчеты по потреблению корма и определяет, кто может участвовать в контактном
зоопарке.

## Архитектура решения
- `IAlive` и `IInventory` разделяют обязанности между живыми существами и любыми объектами,
  находящимися на балансе зоопарка.
- Базовый класс `Animal` определяет общие свойства животных. Производные `Herbo` и `Predator`
  добавляют специфику травоядных и хищников, а конкретные виды (`Monkey`, `Rabbit`, `Tiger`,
  `Wolf`) демонстрируют расширяемость модели.
- Материальные ценности описаны классами `Thing`, `Table`, `Computer`.
- `VeterinaryClinic` принимает стратегию `HealthInspection`, что позволяет легко заменить
  способ проверки здоровья (например, в тестах используется заглушка).
- `Zoo` агрегирует животных и имущество, рассчитывает расход корма и формирует списки для
  контактного зоопарка.
- Консольная оболочка `ZooConsole` организует взаимодействие с пользователем, а простое
  DI-решение `ServiceRegistry` создает и кеширует зависимости.

## Применение SOLID
- **SRP** — `Zoo`, `VeterinaryClinic`, `ServiceRegistry`, `ZooConsole` и другие компоненты имеют
  четко определенные зоны ответственности.
- **OCP** — добавление нового животного или предмета реализуется созданием нового класса без
  изменения существующего кода.
- **LSP** — иерархия животных сохраняет контракт `Animal`: любое животное можно обрабатывать
  через базовый тип.
- **ISP** — `IAlive` и `IInventory` не заставляют реализовывать лишние методы.
- **DIP** — `Zoo` зависит от абстракции `VeterinaryClinic`, а клиника — от интерфейса
  `HealthInspection`; внедрение происходит через `ServiceRegistry`.

## Запуск приложения
```bash
./gradlew clean build
java -jar build/libs/moscow-zoo-1.0.0.jar
```

Во время работы доступно меню:
1. Принять животное (с учетом решения ветеринарной клиники).
2. Добавить предмет на баланс.
3. Показать суммарный расход еды.
4. Вывести животных, подходящих для контактного зоопарка.
5. Показать все инвентарные объекты.
0. Завершить работу.
